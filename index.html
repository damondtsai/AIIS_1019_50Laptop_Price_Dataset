📌 Product 欄位高基數 (High Cardinality) 評估說明：
資料集中 Product 欄位在 1,303 筆樣本中包含高達 618 種獨立型號（基數比率達 47.4%）。若將其進行 One-Hot 編碼，將引入 600+ 個極度稀疏的二元虛擬變數，在訓練樣本僅 1,042 筆的情況下，會導致維度災難 (Curse of Dimensionality)、矩陣奇異性與嚴重的過擬合 (Overfitting)。由於筆電的實質效能與成本皆已由 CPU、GPU、RAM、SSD/HDD、螢幕等具體規格完整體現，因此我們依據統計學習原則將 Product 排除於多元線性迴歸特徵外，確保模型之強健性與泛化能力。

🔬 三種特徵選擇方法對比 (ANOVA · RFE · LassoCV)

Python 實際運算輸出；RFE 與 LassoCV 均嚴格實施標準化縮放 (StandardScaler)

ANOVA F-test 特徵選擇原理：
透過單因子變異數分析 (One-way ANOVA) 計算各個候選特徵與筆電售價 Price_euros 的單變數線性關聯強度。F 值越高且 p-value 越小，表示該特徵在未考慮其他變數情況下的單獨預測力越強。
優點：運算速度極快、直觀易懂；局限：無法偵測特徵間的多元共線性 (Multicollinearity) 與組合協同效應。
排名 特徵名稱 F 檢定統計值 (F-Score) 顯著性 p-value 白話解說與特徵意涵
RFE (Recursive Feature Elimination) 原理：
以標準化後的多元線性迴歸作為基礎估計器 (Estimator)，在每次迴圈中擬合模型，並逐步剔除權重絕對值最小的特徵，遞迴運算直至特徵排序完成。
特徵觀察：RFE 能兼顧變數間的多元相關性。例如 Notebook 與 Workstation 型號能大幅區分一般平價機與高階工作站，因此在 RFE 中排名顯著提高。
保留優先順序 特徵名稱 RFE 評定等級 多元協同效應說明
LassoCV (L1 Regularization) 特徵稀疏化原理：
在標準化特徵矩陣上加入 L1 懲罰項 $\alpha \sum |\beta_j|$，透過 5-Fold 交叉驗證自動搜尋最佳懲罰參數 α。Lasso 的幾何特性會將冗餘或貢獻微弱的特徵係數直接收縮歸零，自然達成特徵挑選。
方法差異體會：三種方法中，ANOVA 偏好單變數相關強者（RAM、SSD），RFE 著眼消除互補殘差，Lasso 則直接懲罰多餘的虛擬類別變數，忠實呈現各方法的統計本質差異。
排名 特徵名稱 標準化迴歸係數 (β) 係數絕對值 |β| 篩選狀態 白話解說

      🧭 CRISP-DM 跨行業資料探勘標準流程實踐

      依循標準資料科學方法學，從商業理解到靜態無伺服器架構部署

      1

      商業與問題理解 (Business Understanding)

      在消費性電子市場中，筆電定價深受 CPU 世代、RAM、SSD 容量及螢幕規格等複雜硬體配置之影響。建立透明、可解釋且無黑箱的線性價格基準模型，有助於評估硬體零件的實質溢價與邊際成本。

      2

      資料理解 (Data Understanding)

      載入 1,303 筆筆電紀錄，欄位涵蓋識別碼、品牌、型號、外型、尺寸、解析度、CPU、記憶體、硬碟、顯示卡、系統、重量與售價。確認全表無缺失值，數值分佈涵蓋 €174 至 €6,099，具備高度代表性。

      3

      資料準備與特徵工程 (Data Preparation)

      以 80/20 固定切分 (random_state=42)；正則解析 CPU 時脈、記憶體 SSD/HDD 容量、螢幕 PPI 像素密度；僅依訓練集品牌頻率決定稀有類別合併，配合 OneHotEncoder(handle_unknown='ignore')，杜絕任何資料外洩。

      4

      建模與特徵挑選 (Modeling)

      透過 ANOVA F-test、RFE 及 LassoCV 三種角度剖析特徵顯著性；在 5-Fold 交叉驗證 Pipeline 內逐一評估特徵子集 (k=1~25)，找出泛化誤差最小之特徵組合。

      5

      模型評估 (Evaluation)

      訓練集 5-Fold CV 選定最佳特徵數 k=23 (CV RMSE €340.71)。在從未參與訓練的測試集上取得 RMSE €355.57、MAE €237.99 與 R² 0.7511，確認無過擬合現象並具備穩定的預測能力。

      6

      靜態部署與即時推論 (Deployment)

      將訓練完成之模型截距、係數矩陣與數值範圍輸出為標準 JSON，由純前端 JavaScript 在瀏覽器端即時計算線性方程，相容 GitHub Pages 無伺服器靜態架構，達成零延遲推論。
